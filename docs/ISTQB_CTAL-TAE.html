d) Test automation can only check results that can be verified by code

Select ONE option.

Show answerHide answer

Answer: d TAE-1.1.1

Source note: The source rationale for a) discusses question option b); its rationale for b) discusses option a). The official answer is d.

Question #35 (2 Points) 🔗
